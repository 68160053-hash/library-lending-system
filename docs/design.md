# Design Spec: Book Lending Shop (ร้านยืมหนังสือ)

## 1. แนวคิด: "ห้องสมุดยามเที่ยงคืน"
โลกรอบๆ เป็นท้องฟ้ากลางคืนสีกรมท่าม่วง มีดาวกะพริบ แสงจันทร์ฉายเฉียง ฝุ่นแสงลอย สัญลักษณ์เรืองจางๆ และเส้นขอบฟ้าหอสมุดที่ท้ายหน้า
หน้าแรกคือ "ร้านหนังสือเวทมนตร์ยามค่ำ" หน้าร้านไม้เข้มมีหน้าต่างสีอำพันเรืองแสง ป้ายแขวนแกว่งได้ ชั้นโชว์ปกหนังสือใต้โคมไฟ กดปกแล้วปกเปิดออกเป็นหนังสือเล่มเปิด ส่วนวัตถุกระดาษเดิม (จดหมายตราขี้ผึ้ง บัตรยืม จดหมายแดง สมุดบัญชี) ยังเป็นกระดาษเหมือนเดิม แค่วางอยู่บนฉากกลางคืน
บรรยากาศ: น่าค้นหา แปลก น่าพิศวง ไม่น่ากลัว (ไม่มีผี หัวกะโหลก เลือด หรือเสียงตกใจ)
เป็นงานออกแบบต้นฉบับ แรงบันดาลใจเรื่องโทนสี ปุ่มเม็ดยา กรอบเส้นเงินมุมตัด และฟอนต์ไร้เชิง+เซริฟหัวข้อ ไม่ใช้โลโก้ ฟอนต์ ภาพ ชื่อ หรือถ้อยคำของแฟรนไชส์ใดๆ ภาพเงาปราสาท/หอสมุดทั้งหมดวาดเองเป็น SVG

## 2. Palette และค่า contrast
ตัวแปรอยู่ใน `:root` ของ `assets/css/style.css` (WCAG AA: ข้อความปกติ >= 4.5, ข้อความใหญ่ >= 3, เส้นขอบ/focus ring ที่ไม่ใช่ข้อความ >= 3) คำนวณด้วยสคริปต์ Python ตามสูตร WCAG

แสงอุ่นในร้าน: `--amber #f2b35b` `--amber-soft #ffcf85` (ตัดกับฉากกลางคืนสีเย็น) ไม้ใช้ `--wood-1/-2` ทอง `--gold` ม่วงใช้กับปุ่ม/focus เท่านั้น

โทนกลางคืน: `--night #0e1119` `--night-2 #161a2b` `--indigo #1f1d3d` `--violet #5758ff` `--moon #e8ecff` `--mist #a9b0d6` `--silver #c9cde0` `--gold #d9b45a` `--wood-1 #3a2416` `--wood-2 #24160d` (+ `--link #aab0ff` สำหรับลิงก์บนฉากมืด) โทนกระดาษคงเดิม: paper, ink, crimson, forest, navy

## 4. ชั้นบรรยากาศ (ใส่ใน `<!-- header start/end -->` ทุกหน้า)
`div.atmos` (fixed, `pointer-events:none`, `aria-hidden`) ประกอบด้วย
- ท้องฟ้า: radial-gradient indigo + `.stars` สองชั้น (radial-gradient ซ้ำ กะพริบด้วย opacity)
- `.moonbeam`: แท่งแสงเฉียง linear-gradient โปร่ง
- `.mote` x10: ฝุ่นแสงลอยขึ้นช้าๆ (30-60 วินาที/รอบ)
- `.rune` x4: สัญลักษณ์เรขาคณิต SVG (ไม่ใช่อักษรจริง) opacity .15 ลอยช้ามาก
- ท้ายเว็บ (`<!-- footer -->`): `svg.skyline` เส้นขอบฟ้าหอสมุด ยอดแหลม หน้าต่างโค้ง บางบานเป็นสีทองกะพริบเบาๆ แล้วต่อด้วยแถบสีเดียวกันใส่ข้อความ

## 5. ส่วนประกอบ
- **หัวเว็บ**: sticky โปร่ง+เบลอ โลโก้หนังสือเปิดเรืองม่วง + "BOOK LENDING SHOP" (Cinzel) + บรรทัดไทย "ร้านยืมหนังสือ"; ลิงก์เมนูมีเส้นม่วงเรืองแสงตอน hover/`aria-current`; ขวาสุดเป็นเม็ดยา user-name + role-badge และปุ่มรอง "ออกจากระบบ"; ที่ <= 820px ปุ่มแฮมเบอร์เกอร์ (`aria-expanded`) เปิดเมนูเป็นแผ่นกระจกเข้ม
- **ปุ่ม**: `.btn-primary` เม็ดยาม่วงทึบ #5758ff ตัวอักษรขาว เรืองเมื่อ hover; `.btn-outline` ขอบม่วง; บนกระดาษ (`.paper`) ปุ่มหลักยังเป็นตราขี้ผึ้ง crimson; `.btn-magic` ปล่อยประกายทอง/ม่วง 12 จุด
- **`.frame-silver`**: เส้นเงิน 1px มุมตัด 4 มุม ทำจาก `::before` (สีเงิน) + `::after` (พื้น) ที่ใช้ `clip-path: polygon` ซ้อนกัน ใช้กับช่องค้นหาและแผงของหน้า my-loans
- **`.frame`** (ทองสองชั้น ลายมุมเถาวัลย์): ยังใช้กับจดหมาย บัตรยืม สมุดบัญชี
- **`.paper`**: คลาสบอกว่า "นี่คือวัตถุกระดาษ" ตั้งสีหมึก ฟอนต์ Taviraj ช่องกรอกแบบเส้นบรรทัด focus ring สีน้ำเงิน ปุ่มตราขี้ผึ้ง

## 6. ร้านหนังสือเวทมนตร์ (หน้าแรก)
**หน้าร้าน (hero)**: CSS + inline SVG ขนาดทุกชิ้นเป็น `em` ของ `.facade` (`font-size: max(1.6cqw, 6.5px)`) จึงย่อตามความกว้างร้าน
- ผนังไม้ + ชายคา (`.fascia` ลายฟันปลา, `.awning` ลายทางพร้อมขอบหยัก) หน้าต่างบานใหญ่สีอำพัน (ปกโชว์ 5 เล่มบนขาตั้ง กองหนังสือ โคมไฟแขวน คานหน้าต่าง รอยสะท้อนกระจก) ประตูโค้งมีกระดิ่ง
- ป้าย "Book Lending Shop / ร้านยืมหนังสือ" (เป็น `<h1>`) แขวนโซ่ 2 เส้น แกว่งด้วย `swing` (`transform-origin: top`) hover แกว่งแรงขึ้นเร็วขึ้น; <= 760px ป้ายอยู่ในกระแสปกติใต้ชายคา ไม่ทับหน้าต่าง
- ประตูเป็นลิงก์ `#shelves` (โฟกัสได้) hover/focus = กระดิ่งสั่น + คำ "ติ๊ง" ลอยขึ้น (`aria-hidden`)
- "Lumos": JS ตั้ง `--mx/--my` เมื่อ pointermove เหนือ hero แล้ว `.shop::after` เป็น radial-gradient อุ่นตามเคอร์เซอร์ (เฉพาะเมาส์ ปิดเมื่อ reduced motion)
- พารัลแลกซ์: scroll listener ตัวเดียวตั้ง `--sy` (0-600) ที่ hero; หลังคาไกล / หน้าร้าน / ป้าย ใช้ `translateY(calc(var(--sy) * k px))` ค่า k ต่างกัน (-.1, .04, .1)
- ใต้ร้านคือคำโปรยและฟอร์มค้นหา (`label` ครบ ฟอร์ม GET เดิม)

**ป้ายหมวด** (`.sign-rail`): ปุ่มป้ายไม้ห้อยจากคาน ใช้ `aria-pressed` ป้ายที่เลือกห้อยต่ำลง 14px และเรืองอำพัน กรองฝั่งเบราว์เซอร์ด้วย JS (progressive enhancement; PHP จริงใช้ GET เช่น `?group=myth`) เล่มที่ไม่ตรงจางลง 180ms แล้วซ่อน เล่มที่กลับมาเด้งเข้า ช่องค้นหากรองสดตามชื่อ/ผู้แต่ง (ไม่สนตัวพิมพ์) และ select หมวดกรองร่วมกันได้ ข้อความ `#status` (`aria-live="polite"`) บอกจำนวน หรือ "ยังไม่มีหนังสือที่ตรงกัน ลองคำอื่นดูนะ"

**ชั้นโชว์** (`.shelf-row` x3 ชั้นละ 6 เล่ม รวม 18): ผนังไม้เข้มมีแสงอำพันใต้โคมแขวน 3 ดวง (แกว่งเบาๆ) ขอบชั้นไม้ด้านหน้าวาดที่ `li::after` ต่อกันเป็นแถบเดียว กริด 6 คอลัมน์ (>= 900px) 3 คอลัมน์ (< 900px) 2 คอลัมน์ (< 600px) จึงเต็มชั้นเสมอ
- ปก (`button.book` > `.pages` + `.face`): สัดส่วน 2:3 สีฐาน `--c` เฉดสันซ้าย ลายผ้า (gradient) ลาย noise กรอบทอง ตราสัญลักษณ์ SVG จาก sprite (`<use href="#e-...">`: ตึก ขวดยา พระจันทร์ เมฆ กุญแจ โคม ปริซึม ใบไม้ ฐานข้อมูล ดาว เข็มทิศ เปลวไฟ วงก้นหอย คลื่น นาฬิกา ตา ขนนก) ชื่อเรื่องทองขึ้นบรรทัดใหม่ครบ (ขนาดตัวอักษรใช้ `cqw` ตามความกว้างปก) ขอบกระดาษด้านขวา/ล่าง และเงาตกบนชั้น
- ป้ายห้อยเชือก 2 ใบ ("ว่าง 2/3" หรือ "ถูกยืมหมด", "ซื้อได้ ฿450" เมื่อมีราคาขาย) แกว่งตอน hover; โน้ต staff pick (Charm) 3 เล่ม; ริบบิ้น "ใหม่" 2 เล่ม
- hover/focus: ปกยก 8px เอียง 3D ตามเมาส์ (`--rx/--ry` จาก JS เฉพาะเมาส์) แสงวาบพาดปก; คลิก/Enter: `.is-open` หมุน `.face` rotateY(-160deg) จากขอบซ้าย 450ms แล้ว JS เปิด dialog (reduced motion = เปิดทันที) คืน focus ให้เล่มเดิมตอนปิด
- dialog: เพิ่มบรรทัดราคา "ซื้อได้ ฿..." และปุ่มรอง "ซื้อเล่มนี้" เมื่อมี `data-sale` (เล่มที่ถูกยืมหมดยังซื้อได้)
- สุ่มปก 1 เล่มขยับเองทุก 6-9 วินาที (`.is-wiggle`)

**หนังสือแนะนำคืนนี้** (`.feature`): หนังสือเล่มเปิดบนที่วางไม้ หน้าซ้ายเป็นปกจำลอง หน้าขวาเป็นชื่อ/คำโปรย/ปุ่ม "ดูรายละเอียดและยืม" (เปิด dialog) ฝุ่นแสงลอย ปุ่มลูกศรสลับ 3 เล่ม (เล่มที่มี `data-pick`) ส่วนข้อความอยู่ใน `aria-live="polite"` <= 599px หน้าซ้าย/ขวาเรียงซ้อนกัน

## 7. วัตถุหน้าอื่น
1. **login / register**: จดหมายตราขี้ผึ้งตัว B ลอยขึ้นลงช้าๆ มีขอบเรืองม่วง + แสงหลังจดหมาย (หยุดลอยตอน hover/focus เพื่อกรอกฟอร์มสะดวก)
2. **my-loans**: บัตรยืม (ตาราง ตราวันที่ ตราสถานะ) อยู่ใน `.frame-silver` หัว eyebrow "MY BORROWING"; <= 900px แถวกลายเป็นการ์ด label: value ผ่าน `data-label`
3. **overdue**: จดหมายแดงบนฉากมืด eyebrow "OVERDUE NOTICES"
4. **book-form**: สมุดบัญชีบนฉากมืด

## 9. Accessibility
- ทุก input มี `<label for>`; error ผูก `aria-describedby` + `aria-invalid`; กล่องแจ้งเตือน `role="alert"`
- `:focus-visible` วงม่วง 2px offset 3px (บนกระดาษใช้สีน้ำเงิน); ปุ่ม/ลิงก์/ช่องกรอกสูง >= 44px (ปกหนังสือกว้างกว่า 130px ป้ายหมวดสูง >= 44px)
- SVG ตกแต่งทั้งหมดและ `.atmos` เป็น `aria-hidden`; หน้าต่างร้าน (ของตกแต่ง) `aria-hidden` ประตูเป็นลิงก์ที่มี `aria-label`; ป้ายหมวดใช้ `aria-pressed`; ข้อความผลกรองใช้ `aria-live="polite"`
- `<dialog>` มี `aria-labelledby`; ลิงก์ "ข้ามไปยังเนื้อหา"; `aria-current="page"`; ไม่ใช้อีโมจิ; สถานะมีข้อความกำกับ ไม่พึ่งสีอย่างเดียว

## 10. แปลงเป็น PHP
1. ตัดส่วน `<!-- header start --> ... <!-- header end -->` ไว้ `includes/header.php` และ `<!-- footer start --> ... <!-- footer end -->` ไว้ `includes/footer.php` (ชั้นบรรยากาศอยู่ใน header, เส้นขอบฟ้าอยู่ใน footer)
2. `aria-current="page"` เช็คจาก `basename($_SERVER['PHP_SELF'])`
3. ข้อความจากผู้ใช้/ฐานข้อมูลครอบ `htmlspecialchars($x, ENT_QUOTES, 'UTF-8')` ก่อน echo (รวมค่าใน `data-*` และ `aria-label` ของปก)
4. เปลี่ยน `CSRF_TOKEN_HERE` เป็นค่าใน `$_SESSION['csrf_token']` และตรวจฝั่งเซิร์ฟเวอร์ทุก POST
5. `foreach` สร้างปกหนังสือ (ชั้นละหมวด) แถวตาราง จดหมายแดง; `--c` ของปกมาจากฐานข้อมูลหรือสุ่มจาก id; `is-out` เมื่อ `copies_available = 0`; `data-sale` ใส่เมื่อมี `sale_price`; การกรองป้ายหมวด/ค้นหาให้ทำด้วย GET + `WHERE ... LIKE ?` (prepared statement) ส่วน JS เป็นแค่ส่วนเสริม
6. ปุ่ม "ยืมหนังสือ" ใน dialog ตอนนี้เป็น `type="button"` ของจริงต้องห่อด้วย `<form method="post">` + csrf_token + hidden book_id (ให้ JS ใส่ค่า `data-id` ของปก) ปุ่ม "ซื้อเล่มนี้" ก็ต้องเป็นฟอร์ม POST + CSRF เช่นกัน และตรวจซ้ำฝั่ง PHP; ปุ่ม disabled ต้องตรวจฝั่งเซิร์ฟเวอร์ด้วย
7. ลิงก์ "ออกจากระบบ" ของจริงควรเป็นฟอร์ม POST + CSRF; SQL ใช้ prepared statement เสมอ
