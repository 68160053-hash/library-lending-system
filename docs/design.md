# Design Spec: Book Lending Shop (ร้านยืมหนังสือ)

## 1. แนวคิด: "ห้องสมุดยามเที่ยงคืน"
โลกรอบๆ เป็นท้องฟ้ากลางคืนสีกรมท่าม่วง มีดาวกะพริบ แสงจันทร์ฉายเฉียง ฝุ่นแสงลอย สัญลักษณ์เรืองจางๆ และเส้นขอบฟ้าหอสมุดที่ท้ายหน้า
หน้าแรกคือ "ชั้นหนังสือ" จริง สันหนังสือยืนบนแผ่นไม้ กดแล้วเปิดเป็นหนังสือเล่มเปิด ส่วนวัตถุกระดาษเดิม (จดหมายตราขี้ผึ้ง บัตรยืม จดหมายแดง สมุดบัญชี) ยังเป็นกระดาษเหมือนเดิม แค่วางอยู่บนฉากกลางคืน
บรรยากาศ: น่าค้นหา แปลก น่าพิศวง ไม่น่ากลัว (ไม่มีผี หัวกะโหลก เลือด หรือเสียงตกใจ)
เป็นงานออกแบบต้นฉบับ แรงบันดาลใจเรื่องโทนสี ปุ่มเม็ดยา กรอบเส้นเงินมุมตัด และฟอนต์ไร้เชิง+เซริฟหัวข้อ ไม่ใช้โลโก้ ฟอนต์ ภาพ ชื่อ หรือถ้อยคำของแฟรนไชส์ใดๆ ภาพเงาปราสาท/หอสมุดทั้งหมดวาดเองเป็น SVG

## 2. Palette และค่า contrast
ตัวแปรอยู่ใน `:root` ของ `assets/css/style.css` (WCAG AA: ข้อความปกติ >= 4.5, ข้อความใหญ่ >= 3, เส้นขอบ/focus ring ที่ไม่ใช่ข้อความ >= 3) คำนวณด้วยสคริปต์ Python ตามสูตร WCAG

โทนกลางคืน: `--night #0e1119` `--night-2 #161a2b` `--indigo #1f1d3d` `--violet #5758ff` `--moon #e8ecff` `--mist #a9b0d6` `--silver #c9cde0` `--gold #d9b45a` `--wood-1 #3a2416` `--wood-2 #24160d` (+ `--link #aab0ff` สำหรับลิงก์บนฉากมืด) โทนกระดาษคงเดิม: paper, ink, crimson, forest, navy

## 4. ชั้นบรรยากาศ (ใส่ใน `<!-- header start/end -->` ทุกหน้า)
`div.atmos` (fixed, `pointer-events:none`, `aria-hidden`) ประกอบด้วย
- ท้องฟ้า: radial-gradient indigo + `.stars` สองชั้น (radial-gradient ซ้ำ กะพริบด้วย opacity)
- `.moonbeam`: แท่งแสงเฉียง linear-gradient โปร่ง
- `.mote` x10: ฝุ่นแสงลอยขึ้นช้าๆ (30-60 วินาที/รอบ)
- `.rune` x4: สัญลักษณ์เรขาคณิต SVG (ไม่ใช่อักษรจริง) opacity .15 ลอยช้ามาก
- ท้ายเว็บ (`<!-- footer -->`): `svg.skyline` เส้นขอบฟ้าหอสมุด ยอดแหลม หน้าต่างโค้ง บางบานเป็นสีทองกะพริบเบาๆ แล้วต่อด้วยแถบสีเดียวกันใส่ข้อความ

## 5. ส่วนประกอบ
- **หัวเว็บ**: sticky โปร่ง+เบลอ โลโก้หนังสือเปิดเรืองม่วง + "BOOK LENDING SHOP" (Cinzel) + บรรทัดไทย "ร้านยืมหนังสือ"; ลิงก์เมนูมีเส้นม่วงเรืองแสงตอน hover/`aria-current`; ขวาสุดเป็นเม็ดยา user-name + role-badge และปุ่มรอง "ออกจากระบบ"; ที่ <= 820px ปุ่มแฮมเบอร์เกอร์ (`aria-expanded`) เปิดเมนูเป็นแผ่นกระจกเข้ม
- **ปุ่ม**: `.btn-primary` เม็ดยาม่วงทึบ #5758ff ตัวอักษรขาว เรืองเมื่อ hover; `.btn-outline` ขอบม่วง; บนกระดาษ (`.paper`) ปุ่มหลักยังเป็นตราขี้ผึ้ง crimson; `.btn-magic` ปล่อยประกายทอง/ม่วง 12 จุด
- **`.frame-silver`**: เส้นเงิน 1px มุมตัด 4 มุม ทำจาก `::before` (สีเงิน) + `::after` (พื้น) ที่ใช้ `clip-path: polygon` ซ้อนกัน ใช้กับช่องค้นหาและแผงของหน้า my-loans
- **`.frame`** (ทองสองชั้น ลายมุมเถาวัลย์): ยังใช้กับจดหมาย บัตรยืม สมุดบัญชี
- **`.paper`**: คลาสบอกว่า "นี่คือวัตถุกระดาษ" ตั้งสีหมึก ฟอนต์ Taviraj ช่องกรอกแบบเส้นบรรทัด focus ring สีน้ำเงิน ปุ่มตราขี้ผึ้ง

## 6. ชั้นหนังสือ (หน้าแรก)
- ฮีโร่: หน้าต่างโค้งแหลม (SVG) เห็นพระจันทร์ ดาว และเงาปราสาท มีเทียน 4 เล่มลอยอยู่ด้านหน้า (bob + เปลวไฟสั่น) ชื่อ "Book Lending Shop" (Cinzel) บรรทัดไทย "ร้านยืมหนังสือ" (Chonburi) และแถบค้นหา `.ask.frame-silver`
- 3 ชั้นตามหมวด: "ตำนานและเวทมนตร์", "ศาสตร์และวิชาการ", "วรรณกรรมคลาสสิก" ชั้นละ 6 เล่ม (รวม 18 เล่ม เป็นของเดิม 6 เล่มกับของใหม่สมมติ 12 เล่ม) พร้อมของตกแต่ง SVG (ขวดยา เทียนตอ นาฬิกาทราย)
- โครงสร้าง: `section.shelf-block > .shelf > .shelf-scroll > ul.books > li > button.spine` ใต้ชั้นเป็น `.plank` (ไม้ ไล่สี ขอบบนสว่าง เงาใต้ชั้น ขาค้ำสองข้าง)
- สัน: `<button class="spine" style="--w;--h;--c" data-title data-author data-category data-available data-total data-blurb>` ลายหนัง = gradient+noise, แถบทอง, ชื่อแนวตั้ง `writing-mode: vertical-rl`, อักษรย่อผู้แต่ง; `.lean-l/.lean-r` เอียงได้; `.is-out` มืดลง + ริบบิ้น "หมด"
- hover/focus: สันเลื่อนขึ้น 14px เรืองม่วง/ทอง + tooltip ชื่อเรื่อง (>= 900px)
- คลิก: JS ใส่ข้อมูลลง `<dialog class="book-dialog">` (ปกหนัง + หน้ากระดาษ ตรา ว่าง/ถูกยืมหมด ปุ่ม "ยืมหนังสือ" ปิดเมื่อหมด) `showModal()`, Esc ปิดเอง, ปุ่มปิด/คลิกฉากมืดปิด, คืน focus ให้สัน
- สุ่มสัน 1 เล่มขยับเองทุก 6-9 วินาที (`.is-wiggle`, JS ลบ class เมื่อ `animationend`)
- มือถือ: ชั้นเลื่อนแนวนอนในตัวเอง (`overflow-x:auto`, scroll-snap) หน้าเว็บไม่เลื่อนข้าง มีคำใบ้ "เลื่อนดูชั้นหนังสือ" ที่ <= 600px

## 7. วัตถุหน้าอื่น
1. **login / register**: จดหมายตราขี้ผึ้งตัว B ลอยขึ้นลงช้าๆ มีขอบเรืองม่วง + แสงหลังจดหมาย (หยุดลอยตอน hover/focus เพื่อกรอกฟอร์มสะดวก)
2. **my-loans**: บัตรยืม (ตาราง ตราวันที่ ตราสถานะ) อยู่ใน `.frame-silver` หัว eyebrow "MY BORROWING"; <= 900px แถวกลายเป็นการ์ด label: value ผ่าน `data-label`
3. **overdue**: จดหมายแดงบนฉากมืด eyebrow "OVERDUE NOTICES"
4. **book-form**: สมุดบัญชีบนฉากมืด

## 8. แอนิเมชันและ reduced motion
| เอฟเฟกต์ | keyframes |
|---|---|
| ดาวกะพริบ ฝุ่น สัญลักษณ์ลอย แสงในหน้าต่างหอสมุด (ของตกแต่ง อาจจาง) | `twinkle`, `mote`, `rune-drift`, `lamp` |
| ชื่อหน้าแรกเรืองแสง เทียนลอย เปลวสั่น | `glow`, `float`, `flicker`, `flame` |
| สันหนังสือสั่นเอง | `wiggle` |
| จดหมายลอย/คลี่ | `bob`, `unfold` (transform อย่างเดียว) |
| ตราประทับกระแทก | `thunk` (เริ่ม opacity .6, `backwards`) |
| dialog เปิด | `open-book` (scale .94 -> 1) |
กติกา: เนื้อหาจำเป็น (ข้อความ ตรา ปุ่ม ช่องกรอก สันหนังสือ) ไม่เริ่มจาก `opacity:0` และไม่พึ่ง fill-mode `both` แม้แอนิเมชันไม่เล่นก็เห็นครบ
`@media (prefers-reduced-motion: reduce)` ปิด animation/transition ทั้งหมด (แสดงสถานะสุดท้าย) และ JS ข้าม wiggle กับประกาย

## 9. Accessibility
- ทุก input มี `<label for>`; error ผูก `aria-describedby` + `aria-invalid`; กล่องแจ้งเตือน `role="alert"`
- `:focus-visible` วงม่วง 2px offset 3px (บนกระดาษใช้สีน้ำเงิน); ปุ่ม/ลิงก์/ช่องกรอกสูง >= 44px (สันหนังสือกว้าง >= 46px)
- SVG ตกแต่งทั้งหมดและ `.atmos` เป็น `aria-hidden`; หน้าต่างโค้งมี `role="img"` + `aria-label`
- `<dialog>` มี `aria-labelledby`; ลิงก์ "ข้ามไปยังเนื้อหา"; `aria-current="page"`; ไม่ใช้อีโมจิ; สถานะมีข้อความกำกับ ไม่พึ่งสีอย่างเดียว

## 10. แปลงเป็น PHP
1. ตัดส่วน `<!-- header start --> ... <!-- header end -->` ไว้ `includes/header.php` และ `<!-- footer start --> ... <!-- footer end -->` ไว้ `includes/footer.php` (ชั้นบรรยากาศอยู่ใน header, เส้นขอบฟ้าอยู่ใน footer)
2. `aria-current="page"` เช็คจาก `basename($_SERVER['PHP_SELF'])`
3. ข้อความจากผู้ใช้/ฐานข้อมูลครอบ `htmlspecialchars($x, ENT_QUOTES, 'UTF-8')` ก่อน echo (รวมค่าใน `data-*` และ `aria-label` ของสัน)
4. เปลี่ยน `CSRF_TOKEN_HERE` เป็นค่าใน `$_SESSION['csrf_token']` และตรวจฝั่งเซิร์ฟเวอร์ทุก POST
5. `foreach` สร้างสันหนังสือ (ชั้นละหมวด) แถวตาราง จดหมายแดง; `--w/--h/--c` ของสันสร้างจากค่าในฐานข้อมูลหรือสุ่มจาก id; `is-out` เมื่อ `copies_available = 0`
6. ปุ่ม "ยืมหนังสือ" ใน dialog ตอนนี้เป็น `type="button"` ของจริงต้องห่อด้วย `<form method="post">` + csrf_token + hidden book_id (ให้ JS ใส่ค่า `data-id` ของสัน) และตรวจซ้ำฝั่ง PHP; ปุ่ม disabled ต้องตรวจฝั่งเซิร์ฟเวอร์ด้วย
7. ลิงก์ "ออกจากระบบ" ของจริงควรเป็นฟอร์ม POST + CSRF; SQL ใช้ prepared statement เสมอ
