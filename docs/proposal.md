## หัวข้อและ pain point
ห้องสมุดและชั้นหนังสือขนาดเล็กในมหาวิทยาลัยมักจดการยืม-คืนลงสมุดหรือ Excel จึงไม่รู้ว่าหนังสือเล่มไหนว่าง ใครถืออยู่ และใครคืนช้า ค่าปรับต้องนับวันด้วยมือและผิดพลาดได้ง่าย ตัวอย่างเช่น นักศึกษายืมหนังสือแล้วเกินกำหนด 12 วันโดยไม่มีใครสังเกต

## กลุ่มผู้ใช้และทางแก้
- **สมาชิก (นักศึกษา/บุคลากร):** ดู ค้นหา ยืมเอง ต่ออายุ และซื้อหนังสือ ดูประวัติและค่าปรับของตัวเอง
- **เจ้าหน้าที่:** จัดการหนังสือ บันทึกการรับคืน ดูรายการเกินกำหนด
- **ผู้ดูแลระบบ:** ทำแทนเจ้าหน้าที่ได้ และจัดการบทบาทผู้ใช้

พัฒนาเป็นเว็บด้วย PHP และ MySQL ให้ยืม-คืนผ่านระบบ คำนวณวันครบกำหนดและค่าปรับอัตโนมัติ และจำกัดสิทธิ์ตามบทบาท

## ขอบเขต
- **กฎ:** ยืมฟรี 7 วัน ต่ออายุได้ 1 ครั้ง (+7 วัน เฉพาะเมื่อยังไม่เกินกำหนด) ค่าปรับ 5 บาท/วัน คำนวณตอนแสดงผล ไม่เก็บในตาราง
- **ต้องมี:** Login/Logout/สมัครสมาชิก, CRUD หนังสือและหมวด, ยืม/คืน/ต่ออายุ, รายการเกินกำหนดและค่าปรับ, ประวัติของสมาชิก
- **ถ้าเวลาพอ:** ร้านขายหนังสือและประวัติคำสั่งซื้อ, ค้นหา, จัดการบทบาทผู้ใช้
- **นอกขอบเขต:** ชำระเงินออนไลน์, อีเมลเตือน, ติดตามรายเล่ม, จำกัดจำนวนเล่มที่ยืม

## ความปลอดภัย
รหัสผ่าน bcrypt (`password_hash`), prepared statement, `session_regenerate_id(true)` หลัง login, CSRF token ทุกฟอร์ม POST รวม logout, `htmlspecialchars`, ตรวจสิทธิ์ member/staff/admin ฝั่ง server, ทุก UPDATE/DELETE ใส่ owner id, รหัสผ่านฐานข้อมูลอยู่ใน `secret/config.php` ที่ไม่เข้า Git
